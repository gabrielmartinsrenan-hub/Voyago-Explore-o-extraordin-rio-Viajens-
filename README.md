# ✈️ Voyago — Experiências & Viagens Inesquecíveis

Uma plataforma web moderna, elegante e responsiva para a agência de viagens **Voyago**. O projeto foi desenvolvido com foco em alta conversão, experiência do usuário (UX), navegação fluida e design imersivo, permitindo aos usuários explorar destinos globais, filtrar categorias e realizar solicitações de reserva online.

![Voyago Banner](https://images.unsplash.com/photo-1507525428034-b723cf961d3e?auto=format&fit=crop&w=1200&q=80)

---

## 🚀 Funcionalidades Principais

- **Hero Section com Busca Rápida:** Widget interativo para busca por destino, datas de viagem e quantidade de viajantes.
- **Cardápio de Destinos com Filtros Dinâmicos:** Filtro instantâneo por categorias (Praias, Montanhas, Cidades, Históricos e Luxo) sem recarregamento da página.
- **Sistema de Solicitação de Reservas:** Form/Modal interativo para captação de clientes interessados em pacotes específicos.
- **Área de Autenticação (Modal de Login):** Interface para login e gerenciamento de conta dos viajantes.
- **Sessão "Por Que Escolher a Voyago":** Apresentação dos diferenciais como Concierge 24/7, garantia de segurança e turismo sustentável.
- **Depoimentos de Clientes:** Avaliações reais com sistema de classificação por estrelas.
- **Captura de Newsletter:** Formulário de inscrição para envio de promoções e roteiros exclusivos.
- **Notificações Toast Personalizadas:** Feedback visual instantâneo em JavaScript para todas as ações do usuário.

---

## 🛠️ Tecnologias Utilizadas

- **[HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML):** Estrutura semântica e acessível.
- **[Tailwind CSS](https://tailwindcss.com/):** Estilização moderna, responsiva e utilitária com paleta de cores personalizada.
- **[JavaScript (ES6+)](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript):** Lógica interativa de filtros, controle de modais e notificações toast.
- **[Font Awesome](https://fontawesome.com/):** Biblioteca de ícones vetoriais.
- **[Google Fonts](https://fonts.google.com/):** Tipografia *Plus Jakarta Sans* para leitura moderna e limpa.
- **[Unsplash API/Images]:** Fotografias de alta resolução de destinos turísticos internacionais.
